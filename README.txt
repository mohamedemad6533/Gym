IRON TRACK — Android installable PWA

This package is an installable offline-capable web app, not a compiled APK.

To install on Android:
1. Upload/extract this folder to a static HTTPS host (for example GitHub Pages or Netlify).
2. Open the published HTTPS address in Chrome on Android.
3. Tap Chrome menu (⋮) > Install app / Add to Home screen.
4. Launch IRON TRACK from the home screen. The app caches its files and works offline after the first successful load.

Workout data is stored locally in the browser on that phone. Use Export backup from History to save a JSON backup. Clearing Chrome site data can erase records.

The exercise photos are generated illustrative demonstrations, not guaranteed to match the exact machines at your gym. Verify exercise setup with your trainer.
